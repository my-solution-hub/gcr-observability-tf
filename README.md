# AWS China Observability Demo

This project demonstrates observability best practices for AWS China regions.

## Structure

- `app/` - Sample application code
- `tf/` - Terraform infrastructure code
- `scripts/` - Deployment and utility scripts

## AWS China Regions

- `cn-north-1` (Beijing)
- `cn-northwest-1` (Ningxia)

## Getting Started

1. Configure AWS China credentials
2. Deploy infrastructure with Terraform
3. Deploy sample application
4. Monitor with CloudWatch dashboards

## Prerequisites

- AWS China account
- Terraform >= 1.0
- AWS CLI configured for China regions
